# AGENTS.md - Portal Berita Fullpower

## Tujuan Project
Project ini adalah aplikasi portal berita berbasis Laravel, Blade, Vite, TailwindCSS, Alpine.js, MySQL, dan RBAC redaksi memakai `spatie/laravel-permission`.

## Karakteristik Project
- Stack utama: Laravel 12, PHP 8.2+, MySQL, Blade, Vite, TailwindCSS, Alpine.js.
- Fitur utama: publikasi artikel, kategori, tag, komentar, media, video, foto, ads banner, SEO, sitemap, PWA, dan dashboard admin.
- Auth dan role editorial tersedia melalui route `login` dan area `admin`.
- Database development bisa dibangun ulang dari migration dan seeder.

## Struktur Penting
- `app/Http/Controllers/Public`: controller halaman publik.
- `app/Http/Controllers/Admin`: controller dashboard dan CRUD admin.
- `app/Models`: model domain portal berita.
- `database/migrations`: struktur tabel aplikasi.
- `database/seeders`: data awal, role, permission, setting, dan konten dummy.
- `resources/views`: Blade UI publik dan admin.
- `resources/js` dan `resources/css`: asset front-end.
- `routes/web.php`: definisi route utama.
- `public/build`: hasil `npm run build`.

## Cara Kerja di Project Ini
- Baca file terkait sebelum mengubah fitur.
- Ikuti pola Laravel yang sudah ada: controller tipis, model/service sesuai domain, Blade untuk UI.
- Jangan mengubah arsitektur, package, atau desain besar tanpa kebutuhan jelas.
- Untuk instalasi lokal gunakan database `fullpower_news` sesuai `.env`.
- Jika perlu data development bersih, gunakan `php artisan migrate:fresh --seed`.
- Jangan menyalin file database `.ibd` langsung ke data directory MySQL kecuali ada prosedur restore yang terverifikasi dan backup.

## Skill yang Relevan
- Tidak ada skill khusus yang wajib untuk maintenance Laravel biasa.
- Gunakan prosedur umum Codex: baca konteks, ubah kecil, validasi dengan test/build/smoke test.
