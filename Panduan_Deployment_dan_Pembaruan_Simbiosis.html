2. Matriks Pemecahan Masalah (Troubleshooting Guide)
Gejala Masalah Penyebab Potensial Solusi Langsung
Error 500 Internal Server Izin folder storage belum 775 atau file .env belum terbaca. Jalankan chmod -R 775 storage bootstrap/cache dan periksa storage/logs/laravel.log.
Gambar Artikel 404 / Hilang Symlink storage publik belum terbentuk atau putus. Hapus link lama lalu pasang ulang: rm -f public/storage && php artisan storage:link.
Perubahan Kode Tidak Muncul OPcache PHP atau cache route/view Laravel masih aktif. Bersihkan cache dengan: php artisan optimize:clear && php artisan view:clear.
Gagal Login Admin 419 Page Expired CSRF Token mismatch atau permission session directory terkunci. Pastikan APP_URL=https://simbiosis.news memakai HTTPS dan bersihkan cookie browser.
